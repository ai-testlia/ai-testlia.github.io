中二銜接練習：國外旅遊
（擴闊眼界與文化體驗）

潘SIR中文教室編撰

💡 學習目標：出國旅遊是大家最喜歡的活動之一！本練習旨在幫助同學掌握描寫旅行見聞的核心詞彙，並訓練同學將「英文思考邏輯」流暢地轉化為地道、標準的中文書面語，擺脫「港式英語（Chinglish）」的句式。

一、供詞填充
詞語教學：四字詞語
字詞解釋例句
迫不及待形容心情急切，急於做某事，無法等待。他迫不及待地打開生日禮物。
大開眼界形容看到新奇事物，眼界大大擴闊，增長見識。參觀科學館後，我對太空知識大開眼界。
流連忘返形容留戀某地美好的景物，捨不得離開。海灘的夕陽美景令遊人流連忘返。
入鄉隨俗到一個新地方，便隨從當地的風俗習慣。到日本旅遊時，我們應該入鄉隨俗，脫鞋進屋。
滿載而歸形容收穫豐富，帶著大量成果歸來。這次購物節，媽媽滿載而歸。
走馬看花比喻粗略地觀察事物，不深入了解。時間緊迫，我們只能走馬看花地遊覽博物館。
興致勃勃形容興趣濃厚，情緒高昂。同學們興致勃勃地討論旅行計劃。
風塵僕僕形容旅途奔波勞累的樣子。爸爸風塵僕僕地從機場趕回家。
依依不捨形容捨不得離開，留戀不已。畢業典禮上，同學們依依不捨地道別。
嘆為觀止形容事物精妙美好到極點，令人讚嘆。故宮的建築藝術令遊客嘆為觀止。

1.經過十多個小時的長途飛行，我們地抵達了倫敦的酒店。
✅ 答案：風塵僕僕
2.一放下行李，弟弟就地拉着爸爸出門，要去品嚐當地的特色美食。
✅ 答案：迫不及待
3.這次參觀法國羅浮宮，欣賞了無數珍貴的藝術品，真讓我。
✅ 答案：大開眼界
4.去到外國旅遊，我們應該，尊重當地的文化和生活習慣。
✅ 答案：入鄉隨俗
5.大峽谷壯麗的自然景色，氣勢磅礴，讓每一位遊客都。
✅ 答案：嘆為觀止
6.跟旅行團出遊往往行程緊密，每個景點只能，無法深入了解當地的歷史。
✅ 答案：走馬看花
7.這座古城充滿了濃厚的歷史氣息和特色小店，讓我們逛了一整天依然。
✅ 答案：流連忘返
8.第一天滑雪雖然常常跌倒，但大家還是地在雪地上玩耍。
✅ 答案：興致勃勃
9.在夜市裏，媽媽買了許多精緻的手信送給親戚朋友，我們一家可說是。
✅ 答案：滿載而歸
10.假期結束了，我們帶着美好的回憶，地踏上了歸途。
✅ 答案：依依不捨
二、不供詞填充
詞語教學：兩字詞語
字詞解釋例句
啟程出發、起程，開始旅程。明天清晨我們就要啟程前往機場。
陌生不熟悉、未曾接觸過。初到異地，一切都顯得十分陌生。
溝通彼此交流、傳遞訊息和想法。即使語言不通，我們仍能用手勢溝通。
迷路迷失方向，找不到原本要走的路。我們在陌生的街道上迷路了。
悠閒輕鬆自在，不慌不忙。假日裏，他喜歡悠閒地在公園散步。
獨特獨有的、與眾不同的。每個地方都有其獨特的文化特色。
嚮往心裏熱切地期盼、渴望。她一直嚮往到巴黎旅行。
體驗親身經歷、感受。我們到農場體驗了摘水果的樂趣。
壯觀景象雄偉盛大，氣勢驚人。日出時分的雲海景色十分壯觀。
疲倦身體或精神感到勞累。長途跋涉後，大家都感到十分疲倦。

請根據句子意思及括號內的提示，填寫最合適的詞語（須為兩個字的詞語）。

1.明早我們六點就要去機場，所以今晚必須早點休息，準備。[提示：出發、起程]
✅ 答案：啟程
2.這是我第一次來到這座城市，面對滿街的外語招牌，心裏難免感到有些。[提示：不熟悉、沒有接觸過]
✅ 答案：陌生
3.雖然我不懂說日文，但透過簡單的肢體語言，依然能和當地人進行基本的。[提示：互相交流、傳遞訊息]
✅ 答案：溝通
4.我們在東京市中心不小心了，幸好遇到一位熱心的警察幫忙指路。[提示：迷失方向，找不到原本要走的路]
✅ 答案：迷路
5.這趟旅行我不打算趕行程，只想坐在湖邊的咖啡廳，度過一個的下午。[提示：輕鬆自在、不急忙]
✅ 答案：悠閒
6.每個國家都有其的傳統服飾和節日，這些都是值得我們探索的寶藏。[提示：獨有的、與眾不同的]
✅ 答案：獨特
7.瑞士的阿爾卑斯山一直是我非常的旅遊勝地，今年終於有機會親臨其境。[提示：心裏熱切地嚮往、渴望]
✅ 答案：嚮往
8.為了更深入地了解泰國文化，我們決定報名參加當地的廚藝班，親自煮泰國菜的樂趣。[提示：親身經歷、體會]
✅ 答案：體驗
9.站在觀景台上，俯瞰整個城市的璀璨夜景，場面非常。[提示：景象宏偉、氣勢盛大]
✅ 答案：壯觀
10.連續走了三天山路，大家的雙腿都感到十分，一上旅遊巴就睡着了。[提示：身體勞累、非常累]
✅ 答案：疲倦 / 勞累
三、改寫句子（英譯中強化訓練）

以下句子為同學日常思考時常用的英文表達。請把它們翻譯並改寫成流暢自然、符合中文語法的標準書面語。

1.I am so excited to travel to Japan with my family this summer holiday.
✅ 參考答案：這個暑假能和家人一起去日本旅遊，我感到十分興奮。
2.The scenery of the Swiss Alps is very beautiful and takes my breath away.
✅ 參考答案：瑞士阿爾卑斯山的風景非常優美，令人歎為觀止。
3.We took a lot of photos in front of the Eiffel Tower.
✅ 參考答案：我們在艾菲爾鐵塔前拍了許多照片。
4.I bought many souvenirs for my classmates at the night market.
✅ 參考答案：我在夜市買了許多手信給班上的同學。
5.The local food is too spicy, so I cannot eat it.
✅ 參考答案：當地的食物太辣了，所以我吃不慣（或：所以我無法進食）。
6.We got lost in the city centre because we couldn't read the map.
✅ 參考答案：因為我們看不懂地圖，所以在市中心迷路了。
7.The flight was delayed for three hours, which made us very frustrated.
✅ 參考答案：航班延誤了三個小時，這讓我們感到十分沮喪（或：無奈）。
8.You should try to speak the local language when you order food.
✅ 參考答案：你點餐時，應該嘗試使用當地的語言。
9.It is important to respect different cultures when we travel abroad.
✅ 參考答案：出國旅遊時，尊重不同的文化是十分重要的。
10.We packed our luggage last night and we are ready to go to the airport.
✅ 參考答案：我們昨晚已經收拾好行李，準備前往機場了。
四、重組句子

請將下列散落的詞組重新組合成邏輯嚴謹、文句通順的書面語句子（需加上適當的標點符號）。

1.買了 / 紀念品 / 許多 / 回國 / 哥哥 / 送給 / 特色 / 朋友
✅ 參考答案：哥哥買了許多特色紀念品回國送給朋友。
2.品嚐 / 我們 / 道地的 / 決定 / 街頭小食 / 去夜市 / 今晚
✅ 參考答案：今晚我們決定去夜市品嚐道地的街頭小食。
3.無數 / 吸引了 / 壯麗的 / 富士山 / 景色 / 遊客 / 前來參觀
✅ 參考答案：富士山壯麗的景色吸引了無數遊客前來參觀。
4.非常 / 感到 / 這次 / 新奇 / 對於 / 弟弟 / 歐洲之旅
✅ 參考答案：對於這次歐洲之旅，弟弟感到非常新奇。
5.不僅能 / 增廣見聞 / 出國旅遊 / 放鬆心情 / 還能 / 讓我們
✅ 參考答案：出國旅遊不僅能讓我們放鬆心情，還能增廣見聞。
6.充滿了 / 歷史氣息 / 漫步在 / 讓我 / 這座 / 感到 / 古城中
✅ 參考答案：漫步在這座古城中，讓我感到充滿了歷史氣息。
7.詳細的 / 為了 / 爸爸 / 旅遊計劃 / 避免迷路 / 制定了 / 提前
✅ 參考答案：為了避免迷路，爸爸提前制定了詳細的旅遊計劃。
8.依依不捨地 / 踏上 / 結束後 / 旅程 / 歸途 / 大家
✅ 參考答案：旅程結束後，大家依依不捨地踏上歸途。
9.拍照留念 / 著名 / 的 / 紛紛 / 在 / 遊客們 / 地標前
✅ 參考答案：遊客們紛紛在著名的地標前拍照留念。
10.最期待的 / 就是 / 這趟 / 滑雪體驗 / 旅程中 / 莫過於 / 環節
✅ 參考答案：這趟旅程中最期待的環節，莫過於滑雪體驗。
五、段落理解

閱讀以下兩段短文，並回答問題。

【文章一】
上個月，我和家人去了一趟東京。這是我第一次來到這個繁華的大都市。我們第一站去了著名的淺草寺，那裏人山人海，各式各樣的傳統手工藝品讓我大開眼界。午餐時，我們入鄉隨俗，在一家地道的居酒屋品嚐了美味的拉麵和刺身。雖然我不懂日文，但店員熱情的笑容和簡單的英語，讓我們感到十分親切。下午，我們在新宿的街頭不小心迷路了，幸好遇到一位熱心的當地人為我們指路，才順利回到酒店。這趟旅行讓我體驗了日本獨特的文化，也感受到當地人的友善。
1.作者和家人到了東京後，第一站去了哪裏參觀？
✅ 參考答案：他們第一站去了著名的淺草寺。
2.文中哪個四字成語形容作者看到傳統手工藝品時，感到眼界大開、增長見識？
✅ 參考答案：大開眼界。
3.作者在居酒屋遇到甚麼困難？他們最後是如何解決的？
✅ 參考答案：作者不懂日文。他們靠着店員熱情的笑容和簡單的英語來溝通解決。
4.在新宿街頭，作者一家遭遇了甚麼小意外？
✅ 參考答案：他們在新宿的街頭不小心迷路了。
5.根據文章結尾，這次東京之旅讓作者有哪兩方面的體會？
✅ 參考答案：體驗了日本獨特的文化，並感受到當地人的友善。

【文章二】
去年的暑假，我們一家飛往新西蘭，展開了一場難忘的自然之旅。遠離了城市的喧囂，我們租了一輛露營車，沿途欣賞壯麗的湖泊和連綿的雪山。其中最讓我難忘的，是乘坐直升機俯瞰冰川。從高空望下，那晶瑩剔透的巨大冰層在陽光下閃閃發光，大自然的鬼斧神工真令人嘆為觀止。晚上的時候，我們把車停在湖邊，抬頭便能看見滿天繁星。雖然旅途奔波，有時還會感到疲倦，但這種悠閒自在、與大自然親密接觸的體驗，實在讓我流連忘返，捨不得離開。
6.作者一家在新西蘭選擇了甚麼特別的交通方式來旅遊？
✅ 參考答案：他們租了一輛露營車。
7.整個行程中，最讓作者難忘的活動是什麼？
✅ 參考答案：乘坐直升機俯瞰冰川。
8.文中哪個四字成語形容大自然的景色雄偉壯觀，令人讚嘆？
✅ 參考答案：嘆為觀止。
9.除了欣賞冰川外，他們在晚上還欣賞了甚麼自然景色？
✅ 參考答案：他們在湖邊抬頭欣賞滿天繁星。
10.雖然旅途會感到疲倦，但為甚麼作者依然「流連忘返」？
✅ 參考答案：因為他非常喜歡這種悠閒自在、與大自然親密接觸的體驗。
