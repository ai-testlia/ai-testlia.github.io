潘 Sir 中文教室編撰

💡 學習目標：本練習專為國際學校及海外回流的中三同學而設。透過藝術展覽、流行音樂會、運動競賽等課外活動情境，協助同學掌握中三級程度的核心詞彙，並訓練將「英語思維」精準轉化為流暢的高階中文書面語。

一、供詞填充

📖 詞語解釋與例句（請先掌握以下詞語的意思，再完成下面的填充練習）

詞語解釋例句
賞心悅目形容眼前景物美好，令人看了心情愉快。公園裡種滿了各種顏色的花，環境賞心悅目。
餘音繞樑形容歌聲或音樂優美動聽，餘韻久久不散，令人回味。她的歌聲餘音繞樑，觀眾散場後仍然念念不忘。
引人入勝形容事物十分吸引，使人產生濃厚興趣，欲罷不能。這本推理小說的情節引人入勝，我一口氣看完了。
拍案叫絕形容對某事物讚賞到極點，忍不住拍桌叫好。觀眾對雜技演員高難度的表演拍案叫絕。
栩栩如生形容藝術形象生動逼真，如同活的一樣。博物館裡的蠟像栩栩如生，讓人幾乎分不清真假。
雅俗共賞形容作品既有藝術水平，又能為普通大眾接受和欣賞。這套動畫電影老少咸宜，可謂雅俗共賞。
陶冶性情指透過藝術、閱讀等活動，潛移默化地培養美好的品格和情操。家長鼓勵孩子學習樂器，藉此陶冶性情。
汗流浹背形容出汗很多，濕透了背部的衣服，多用於形容天氣炎熱或運動勞累。搬完這幾箱書，他已經汗流浹背。
樂在其中形容從某件事情中得到樂趣，即使辛苦也感到快樂。雖然練習很辛苦，但他一直樂在其中。
意猶未盡形容興致還沒有得到滿足，還想繼續下去。這頓飯吃得意猶未盡，下次還要再來。

1.這部科幻電影的視覺特效非常震撼，劇情更是，讓全場觀眾目不轉睛。
✅ 答案：引人入勝
2.學習書法不僅能練出一手好字，更能在靜心書寫的過程中。
✅ 答案：陶冶性情
3.經過兩個小時的劇烈籃球比賽，所有隊員都，但臉上卻掛着滿足的笑容。
✅ 答案：汗流浹背
4.這位著名歌手的嗓音清澈動人，演唱會結束後，美妙的歌聲彷彿依然。
✅ 答案：餘音繞樑
5.博物館裏展出的立體雕塑，連人物衣服上的細小皺褶都雕刻得十分細緻。
✅ 答案：栩栩如生
6.這套喜劇的題材既有深度又充滿幽默感，真是一部的優秀作品。
✅ 答案：雅俗共賞
7.雖然排練舞台劇的過程十分艱辛，但看到團隊合作的成果，大家都。
✅ 答案：樂在其中
8.魔術師在舞台上表演了神乎其技的脫逃魔術，令台下觀眾，掌聲雷動。
✅ 答案：拍案叫絕
9.演唱會已經超時，但歌迷們依然，在台下大喊「安歌（Encore）」。
✅ 答案：意猶未盡
10.植物園裏開滿了五顏六色的鬱金香，風景，是週末散步的好去處。
✅ 答案：賞心悅目
二、不供詞填充

📖 詞語解釋與例句（請先掌握以下詞語的意思，再完成下面的填充練習）

詞語解釋例句
培養以較長時間栽培或訓練，使某種特質、能力或興趣得以發展。閱讀習慣需要從小培養。
精彩形容表演、內容等特別優秀、出色，令人讚賞。這場籃球賽的最後一節十分精彩。
舒緩 / 緩解使緊張、痛苦或壓力等的程度減輕。聽輕音樂有助舒緩緊張的情緒。
展覽把物品陳列出來，供公眾參觀。學校美術組將於下月舉行作品展覽。
節奏音樂或動作中有規律的強弱、快慢變化。這首歌的節奏輕快，令人不禁想跟着打拍子。
鍛鍊通過反覆練習或運動，使身體或能力變得強健、熟練。他每天早上跑步鍛鍊身體。
喝彩 / 歡呼大聲叫好，表示讚賞或興奮。球員射入致勝一球，全場觀眾都站起來喝彩。
投入全神貫注地參與某件事情，形容專注、用心。她演戲十分投入，完全融入了角色。
氛圍 / 氣氛周圍環境所形成的氣息、情調。聖誕節的商場總是充滿歡樂的氛圍。
欣賞領略事物的美好之處，加以享受和讚賞。媽媽喜歡在假日到畫廊欣賞藝術品。

請根據句子意思及括號內的提示，填寫最合適的詞語（須為兩個字的詞語）。

1.學校每年都會舉辦不同類型的課外活動，藉此學生多方面的興趣。[提示：照料培育，使之發展]
✅ 答案：培養
2.這場管弦樂團的演出非常，我們全家都聽得如癡如醉。[提示：優美出色、引人入勝]
✅ 答案：精彩
3.週末時，我喜歡到海濱長廊跑步，因為運動能夠有效我平日的學習壓力。[提示：使緊張的情緒或壓力得到減輕]
✅ 答案：舒緩 / 緩解
4.西九文化區的M+博物館最近舉辦了一個大型的現代藝術，吸引了許多年輕人參觀。[提示：把物品陳列出來供人觀看]
✅ 答案：展覽
5.隨着輕快的音樂，舞蹈員在台上展現出充滿活力的舞姿。[提示：音樂中交替出現的有規律的強弱、長短現象]
✅ 答案：節奏
6.體育老師鼓勵我們每天堅持游泳，這樣才能有效強健的體魄。[提示：通過體育運動使身體強壯]
✅ 答案：鍛鍊
7.看見主場球隊在最後一秒鐘投進致勝的三分球，全場球迷都激動地站起來。[提示：大聲叫好，表示讚賞]
✅ 答案：喝彩 / 歡呼
8.由於這首流行曲的旋律非常洗腦，同學們很快便完全在演唱會的狂熱之中。[提示：形容全神貫注，參與其中]
✅ 答案：投入
9.走進這間歷史悠久的圖書館，四周安靜得只剩下翻書聲，散發着濃厚的學術。[提示：周圍的氣氛和情調]
✅ 答案：氛圍 / 氣氛
10.懂得藝術品，不但能提高個人的審美眼光，還能讓生活增添幾分情趣。[提示：享受美好的事物，領略其中的趣味]
✅ 答案：欣賞
三、改寫句子（英譯中強化訓練）

以下句子為同學日常思考時常用的英文表達。請把它們準確地翻譯並改寫成流暢自然、符合中三級中文語法的標準書面語。

1.I really enjoy going to pop concerts because the live atmosphere is amazing.
✅ 參考答案：我十分喜歡觀看流行音樂會，因為現場氣氛極佳。
2.Playing basketball not only helps me stay healthy but also relieves my stress from studying.
✅ 參考答案：打籃球不僅能讓我保持健康，還能舒緩學習壓力。
3.The art exhibition we visited yesterday was very impressive and eye-opening.
✅ 參考答案：我們昨天參觀的藝術展覽令人印象深刻，讓我大開眼界。
4.I have been learning to play the piano for five years in order to cultivate my patience.
✅ 參考答案：為了培養耐性，我學習彈鋼琴已經五年了。
5.My parents usually take me to the museum on weekends to learn about history.
✅ 參考答案：父母通常會在週末帶我參觀博物館，以認識歷史。
6.We gave a big round of applause to the actors after the drama performance.
✅ 參考答案：戲劇表演結束後，我們給予演員熱烈的掌聲。
7.Doing sports is a good way to build up team spirit with my classmates.
✅ 參考答案：做運動是與同學建立團隊精神的好方法。
8.Reading fantasy novels is my favorite hobby in my free time.
✅ 參考答案：在空餘時間閱讀奇幻小說，是我最喜歡的嗜好。
9.The melody of this classical music is so beautiful that I can't stop listening to it.
✅ 參考答案：這首古典音樂的旋律十分優美，讓我百聽不厭。
10.Participating in extracurricular activities can make our school life more colorful.
✅ 參考答案：參與課外活動能讓我們的校園生活更加多姿多采。
四、重組句子

請將下列散落的詞組重新組合成邏輯嚴謹、文句通順的書面語句子（需加上適當的標點符號）。

1.舒緩 / 聽 / 壓力 / 古典音樂 / 的 / 是 / 方法 / 學習 / 一個 / 很好
✅ 參考答案：聽古典音樂是一個舒緩學習壓力的很好方法。
2.畫展中 / 展出 / 的 / 令人 / 作品 / 這次 / 讚嘆不已 / 藝術
✅ 參考答案：這次畫展中展出的藝術作品令人讚嘆不已。
3.不僅 / 鍛鍊身體 / 培養 / 團隊精神 / 參與 / 體育活動 / 還能 / 能
✅ 參考答案：參與體育活動不僅能鍛鍊身體，還能培養團隊精神。
4.無數 / 攝影比賽 / 參加 / 吸引了 / 舉辦的 / 這次 / 學校 / 學生
✅ 參考答案：這次學校舉辦的攝影比賽吸引了無數學生參加。
5.優美 / 台上的 / 舞蹈員 / 展現出 / 隨着 / 音樂 / 的 / 舞姿
✅ 參考答案：舞蹈員隨着音樂在台上展現出優美的舞姿。
6.留下 / 這部 / 深刻的 / 讓 / 觀眾 / 電影 / 印象 / 緊湊的 / 劇情
✅ 參考答案：這部電影緊湊的劇情讓觀眾留下深刻的印象。
7.歡呼喝彩 / 贏得 / 全場觀眾 / 精彩的 / 為 / 紛紛 / 比賽 / 站起來
✅ 參考答案：全場觀眾紛紛站起來為精彩的比賽歡呼喝彩。
8.投入地 / 舞台劇 / 演藝學會的 / 排練 / 正在 / 禮堂裏 / 同學們
✅ 參考答案：演藝學會的同學們正在禮堂裏投入地排練舞台劇。
9.陶冶性情 / 能夠 / 欣賞 / 我們 / 和 / 藝術品 / 幫助 / 提升品味
✅ 參考答案：欣賞藝術品能夠幫助我們陶冶性情和提升品味。
10.十分 / 的 / 氣氛 / 讓 / 演唱會 / 狂熱 / 歌迷們 / 享受 / 現場
✅ 參考答案：演唱會現場狂熱的氣氛讓歌迷們十分享受。
五、段落理解

閱讀以下兩段短文，並回答問題。

【文章一】
上週末，中文老師安排我們到西九文化區參觀一個現代水墨畫展覽。原本我以為水墨畫只會畫一些沉悶的山水和花鳥，但這次展覽卻讓我大開眼界。展廳內的作品結合了傳統筆墨與西方抽象的藝術元素，其中一幅名為《都市叢林》的畫作更是引人入勝。畫家利用濃淡交錯的墨色，栩栩如生地勾勒出香港高樓林立的壓迫感，同時又保留了一絲寧靜的意境，可謂雅俗共賞。導賞員逐幅解說，我才漸漸看懂畫作背後藏着的情感。這趟參觀陶冶了我的性情，也改變了我對傳統藝術的刻板印象。
1.參觀展覽前，作者對「水墨畫」有什麼既定的刻板印象？
✅ 參考答案：他以為水墨畫只會畫一些沉悶的山水和花鳥。
2.這次展覽中的作品在創作手法上有什麼特別之處？
✅ 參考答案：作品結合了傳統筆墨與西方抽象的藝術元素。
3.文中哪個四字成語形容畫作《都市叢林》十分吸引，讓人不自覺地沉醉其中？
✅ 參考答案：引人入勝。
4.畫家在《都市叢林》這幅畫中，想表達出香港社會的什麼感覺？
✅ 參考答案：高樓林立的壓迫感，同時又保留了一絲寧靜的意境。
5.根據文章結尾，這次展覽為作者帶來了哪兩個正面的影響？
✅ 參考答案：陶冶了他的性情，也改變了他對傳統藝術的刻板印象。

【文章二】
升上中三後，我加入了學校的排球隊。排球是一項極度講求團隊合作的體育運動，單靠個人技術是無法取勝的。每個星期二和星期四的放學後，我們都要在體育館進行嚴格的體能及戰術訓練。雖然每次練完球都汗流浹背、四肢痠痛，但隊員們依然樂在其中。在最近一次的校際比賽中，我們在落後兩局的劣勢下，憑着永不言敗的體育精神和默契，最終逆轉勝出。裁判吹哨結束比賽的一刻，全場同學起立為我們喝彩，站在場上聽着掌聲，我忽然明白，堅持和團結原來這麼珍貴。
6.為什麼作者認為排球運動「單靠個人技術是無法取勝的」？
✅ 參考答案：因為排球是一項極度講求團隊合作的體育運動。
7.排球隊的訓練為作者的身體帶來了什麼反應？
✅ 參考答案：每次練完球都會汗流浹背、四肢痠痛。
8.在最近的校際比賽中，排球隊是如何反敗為勝的？
✅ 參考答案：他們憑着永不言敗的體育精神和默契，最終逆轉勝出。
9.文中哪個雙音節詞語（兩個字）形容觀眾在比賽結束時，大聲叫好以示讚賞？
✅ 參考答案：喝彩。
10.這次比賽的經歷讓作者領悟到什麼道理？
✅ 參考答案：他忽然明白到，堅持和團結原來這麼珍貴。
